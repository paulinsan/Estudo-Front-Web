# Quiz Interativo para Programadores 💻

Projeto desenvolvido com **HTML5 e CSS3** com o objetivo de praticar os fundamentos do desenvolvimento web por meio da criação de um quiz interativo sobre programação.

A página apresenta diferentes tipos de perguntas, elementos HTML semânticos, formulários e uma tabela de pontuação, com um layout personalizado por meio do CSS.

## 📚 Sobre o Projeto

O **Quiz Interativo para Programadores** foi desenvolvido como um projeto de aprendizado para colocar em prática os conhecimentos adquiridos em HTML e CSS.

O quiz aborda conceitos básicos de programação e desenvolvimento web, permitindo explorar diferentes elementos HTML para estruturar perguntas e organizar informações.

O projeto também utiliza uma identidade visual própria, com uma paleta de cores em tons de verde e bege, tipografia personalizada e elementos estilizados com CSS.

## 🚀 Funcionalidades

- **Apresentação do quiz:** introdução e explicação sobre o projeto.
- **Perguntas de múltiplos formatos:** questões com alternativas, campos de texto, senha, data, caixas de seleção e menus suspensos.
- **Upload de arquivos:** campo para selecionar arquivos com extensão `.html`.
- **Identificação por imagem:** pergunta que utiliza o logotipo de uma linguagem de programação.
- **Tabela de pontuação:** classificação do desempenho em iniciante, intermediário e avançado.
- **Gabarito interativo:** exibição das respostas por meio dos elementos `<details>` e `<summary>`.
- **Formulário de feedback:** campos para nome, e-mail e mensagem, com uma confirmação ao clicar no botão de envio.
- **Layout personalizado:** cores, fontes, espaçamentos, bordas e outros elementos estilizados com CSS.

## 🛠️ Tecnologias Utilizadas

### HTML5

Utilizado para estruturar o conteúdo e os elementos da página.

Principais recursos praticados:

- Estrutura básica de um documento HTML.
- Elementos semânticos: `<header>`, `<main>`, `<section>` e `<footer>`.
- Hierarquia de títulos e organização de conteúdo.
- Formulários e diferentes tipos de entrada com `<input>`.
- Elementos `<select>`, `<option>`, `<textarea>` e `<button>`.
- Tabelas com `<table>`, `<thead>`, `<tbody>`, `<th>` e `<td>`.
- Listas ordenadas com `<ol>` e `<li>`.
- Imagens e legendas com `<img>`, `<figure>` e `<figcaption>`.
- Elementos informativos e interativos, como `<abbr>`, `<details>` e `<summary>`.

### CSS3

Utilizado para personalizar a aparência da página e melhorar a organização visual dos elementos.

Principais recursos praticados:

- Reset de margens e espaçamentos com o seletor universal `*`.
- Modelo de caixa com `box-sizing: border-box`.
- Personalização de cores, fontes e tamanhos de texto.
- Organização de elementos com Flexbox.
- Estilização de formulários, campos de entrada e botões.
- Personalização de tabelas, listas e rodapé.
- Uso de seletores por elemento, classe e atributo.
- Importação de fontes externas do Google Fonts.

## 🎨 Identidade Visual

O projeto utiliza uma paleta de cores inspirada em tons naturais, combinando verde, bege e verde-claro.

| Cor | Código | Aplicação |
|---|---|---|
| Bege claro | `#f4f0ea` | Fundo da página |
| Verde oliva | `#798252` | Cabeçalho, rodapé e textos |
| Verde escuro | `#4c5526` | Títulos e textos de destaque |
| Verde-claro | `#ccd595` | Bordas, botões e elementos de destaque |

A fonte utilizada é a **Cabin**, importada do Google Fonts.

## 📁 Estrutura do Projeto

```text
quiz-para-programadores/
├── index.html
├── style.css
└── README.md
```

- `index.html`: contém a estrutura da página, as perguntas, os formulários, a tabela de pontuação e o gabarito.
- `style.css`: contém os estilos responsáveis pela identidade visual e pela organização dos elementos.
- `README.md`: apresenta a documentação do projeto.

## ▶️ Como Executar

1. Clone este repositório ou baixe os arquivos do projeto.
2. Abra a pasta no Visual Studio Code ou em outro editor de código.
3. Verifique se os arquivos `index.html` e `style.css` estão na mesma pasta.
4. Abra o arquivo `index.html` em seu navegador.
5. Explore as perguntas e os elementos disponíveis no quiz.

Não é necessário instalar dependências ou configurar um servidor para visualizar a página localmente.

## ⚠️ Observações

Este projeto tem finalidade educacional e está focado na prática de HTML5 e CSS3.

- O quiz ainda não possui um sistema de correção automática nem cálculo de pontuação.
- Os campos de perguntas permitem interação visual, mas as respostas não são avaliadas automaticamente.
- O formulário de feedback exibe uma mensagem de confirmação, mas ainda não envia os dados para um servidor.
- A pontuação e o gabarito são apresentados como referências para o usuário.

Esses recursos poderão ser aprimorados futuramente com JavaScript.
